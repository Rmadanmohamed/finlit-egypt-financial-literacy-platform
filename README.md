# FinLit Egypt Financial Literacy Platform

## Overview
A financial literacy platform with calculators, educational resources, user account flows, charts, and an Express server.

## Problem Statement
Personal finance education benefits from practical calculators and guided resources that help users understand budgeting, loans, savings, and financial decisions.

## Features
- Express server
- Budget, savings, and loan calculators
- Client-side charts and resources
- Account and assessment flows

## Tech Stack
- Node.js
- Express
- JavaScript
- HTML
- CSS

## Dataset
- Client-side sample/local data files in js/

## Models / Algorithms
- Calculator formulas and educational workflows

## Results
This is a web application; no ML benchmark metric applies.
